# aures guide

How to use aures for what you want to do with it. Each page is a short walk through; the [README](../../README.md) lists everything the app does and every key, and `?` inside the app shows them too.

| I want to… | Page |
|---|---|
| Open a song, loop a passage and slow it down | [Getting started](getting-started.md) |
| Mark sections and chords, and lay a bar grid | [Marking a song](marking.md) |
| Keep my markers and move them to another machine | [Saving](saving.md) |

Your audio never leaves your machine: the browser reads the file locally and nothing is uploaded. If you have no audio at hand, [`demo.mp3`](../../demo.mp3) is a 40-second synthetic track with four different sections, made for trying the app out.
